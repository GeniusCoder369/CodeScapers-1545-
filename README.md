# Case Ledger - Fraud Evidence Organizer

When dealing with financial fraud or scams, victims are often overwhelmed by scattered evidence—WhatsApp chats, bank SMS alerts, UTR numbers, and screenshots.

***Case Ledger*** is a privacy-first tool designed to help victims and support workers log, organize, and export this evidence into a clean, chronological report for banks or authorities.
